WHAT CHANGED (DSSceneHost.m only, plus the version)
- 692 patch: default off (patch=on in the 692 tune to opt in). It is also off whenever the 693 off file
  exists.
- New cog copy: a small view in the strip (tag 69301) with a _UIPortalView of the host view.
    source square: app x src_x, y src_y, size x size (default 12, 139, 44; src_y auto = dst_y + shift,

    opaque (card background colour behind), normal blend, round (cornerRadius = half) by default
    taps: forward mode turns the copy portal's hit testing on (routes to the source square, like the
      strip); otherwise the strip keeps the tap.

  app under it. That's how to see where the cog really is.
- Logs: "phonesize693 tune ...", "phonesize693 <app> cog copy made/updated: source square app x .. y ..
  size .. -> bar x .. y .. (card rect ..)", "no cog copy (reason)", "peek ON/off", latch lines.
