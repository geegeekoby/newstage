          keyboard system names as Beeper's own. Messages' keyboard no longer teaches it K=300.
lift755   kb707 never lifts a phonesize684 card (its keyboard is inside the card);
          the other card still slides aside if they overlap.

          detach line names the app that was really there.

          set when the keyboard system names a staged app, cleared when it turns off.
          No more stale "X is typing" after the keys went down.

focus755  LOG ONLY. At each keyboard on/off for a staged app: key window, and the last
          focus / event-deferring update SpringBoard sent that scene (passed or held, list).
          Empty-list focus updates are logged as "focus755 empty-list focus update".
