CursorRepo - Phone stage aspect-fit build (source only)
=======================================================

Source: Origin uniqu3-nam3/CursorRepo, branch main (tree 3b44c45b).
Every file except the two below matches the Origin git blob byte-for-byte
(each one was checked against its blob SHA).

Replaced with Phone aspect-fit patches:
  springboard/DSStageManager.m
    - New -cardHostsMobilePhone: and -phoneAspectFitFrameInside:.

      restore aspect-fit the card to the device shape (centred) when it hosts
      com.apple.mobilephone. Other apps unchanged.

  app/Tweak.xm
    - DSPhoneScaleRootIntoCard: scale = MIN(cardW / fullW, cardH / fullH)

      DSAdjustPhoneLayoutForStage no longer calls it.
    - Based on Origin blob e2f7895594b5d82de5d5ab5b1da50a5351fa9bc2.
