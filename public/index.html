Installing

  1. Add the repo above, then install Dynamic Stage from it.
  2. Respring when Sileo offers to.
  3. Open Settings › Dynamic Stage and pick the apps you want on the stage. First pull shows a short walkthrough.
  4. Pull up from the bottom-right corner of any app to bring the stage in. Drag it down past halfway for Split View, flick it away to dismiss.

Requirements

Version—
iOS14.0 – 16.7
JailbreakRootless (/var/jb)
Architecturearm64

Built and tested against an iPhone 14 Pro Max on iOS 16.5.1 with NathanLR. Needs ElleKit (or Substitute) and PreferenceLoader, both of which every rootless jailbreak ships with. Rootful jailbreaks are not supported by this build.

Unsigned repo — Sileo will warn about that, which is normal for tweak repos.
